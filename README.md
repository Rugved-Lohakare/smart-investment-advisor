# Smart Investment Advisor
<br>
work in progress
<br>
This project builds a stock trend prediction and news sentiment analysis system
using historical stock data and real-time news from NewsAPI.

## Features
- News collection via NewsAPI
- Cleaning and relevance filtering
- FinBERT sentiment analysis
- Daily sentiment score
- Stock trend modeling

## Tech Stack
Python, Pandas, NewsAPI, NLP, Machine Learning
